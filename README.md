# yokemate

Оркестраторский чат для разработки по многим организациям и репозиториям: обычная сессия pi в корне этого репозитория, открытая в `herdr`, плюс семь скиллов и полтора десятка команд вокруг неё. Тикеты — из YouTrack, состояние — в SQLite; `/do` и `/ship` работают фоновыми coordinator-ами, а разговорные режимы — в собственных панелях.

## Быстрый старт

```bash
pnpm on-me                                        # тикеты на мне, по всем YouTrack
pnpm add-project <клон> --tracker acme:ACME --model openai-codex/gpt-5.6-terra   # подключить репозиторий
```

Дальше в главном чате: `/plan ACME-347` → `/do` → `/review` → `pnpm accept`. Для исследования без тикета есть `/research <project/topic>` — отдельная вкладка.
